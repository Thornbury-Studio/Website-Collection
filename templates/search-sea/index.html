SEA

One search box.
Three destinations.

Search Engine Adapter is a thin Nginx proxy. Type once — it sends you to Google, ChatGPT, or Wikipedia based on the words you use.

ChatGPT Ends with ? — you asked a question, so SEA answers.

How it chooses

Three simple listens. No dashboard. No account.

  1. 01

    Ask → ChatGPT

    If your query ends with a question mark, you want an answer — not a page of links. SEA sends it to ChatGPT.

    why is the sky blue?

  2. 02

    Define → Wikipedia

    Words like “what is”, “wiki”, or “meaning” sound like a lookup. Those go to Wikipedia.

    what is nginx

  3. 03

    Find → Google

    Everything else is still a search. SEA falls through to Google.

    best espresso machines 2026

Why it exists

You already switch between looking things up, asking questions, and browsing results. SEA keeps those three habits behind one URL — the search box you already have.

  • One endpoint

    Point your browser’s default search at SEA. Stop opening three tabs out of habit.

  • Rules, not an app

    A Go program compiles your config into Nginx map directives. There is no web app to host or exploit.

  • Yours to change

    Edit the keywords, add destinations, turn on TLS. Reload Nginx. Done.

Run it on Nginx

Open source from Dense Analysis. Needs Go 1.22+ and Nginx 1.14+.
