# SEA — design

Product site for Search Engine Adapter. Layout copies the A24 film-disc theatre (title, credits, horizontal disc carousel, playlist quotes). Discs are rendered as **music CDs** (printed face, iridescent ring, hub hole), not film Blu-rays.

## Palette

- Stage: `#E4E1DA`
- Ink: `#171512`
- Mute: `#6B6760`
- Accent: `#1A5F6A`

## Type

- Instrument Serif — titles, credits values, quotes
- IBM Plex Sans — nav, labels
- IBM Plex Mono — samples, code

## Interaction

Drag / arrow keys / Index panel to change CDs. Try-box routes `?` → Ask, wiki keywords → Define, else → Find.
