# RELAY — design system

Developer infrastructure: API payment routing. Guide-calm trust language with a
hardcore metric dashboard as **proof overlay** on a real visual world — Kinetic
density, not Kinetic cinema, not AI lab stickers.

## Product

Route money and API traffic with measurable uptime and predictable latency.

## Palette

| Token | Value | Role |
|---|---|---|
| void | `#0B0D10` | page ground |
| surface | `#12151A` | panels / dashboard |
| ink | `#E8EAED` | primary text |
| ink-dim | `#8B939E` | secondary |
| line | `rgba(255,255,255,0.08)` | hairlines |
| accent | `#5EEAD4` | one strong signal per section |
| ok | `#34D399` | status healthy |
| warn | `#FBBF24` | status degraded |
| bad | `#F87171` | status error |

## Typography

- Display: Space Grotesk 600/700
- Body: Instrument Sans 400/500
- Meta / metrics: IBM Plex Mono 400/500

Banned as brand face: Inter, Roboto, Poppins, Arial, bare system-ui.

## Locked media frames

1. **Hero** (`img/hero.webp`) — Dark edge-routing atmosphere: deep slate void, soft teal light paths / glass depth, cinematic infra mood. No UI chrome in the plate. Dashboard overlays in-page.
2. **Stage layers** (`img/stage-layers.webp`) — Dark isometric / glass stacked planes suggesting routing layers (Agency-inspired, teal accents on near-black).
3. **Stage ops** (`img/stage-ops.webp`) — Photographic NOC / rack / cable ops plate, cool teal practicals.
4. **Trust** (`img/trust.webp`) — Quiet secure ops still (hands/console/rack detail).
5. **How** (`img/how-connect.webp`, `how-route.webp`, `how-observe.webp`) — Three tight crops matching Connect / Route / Observe.

## Layout contract

- Hero: brand name largest; full-bleed world; dashboard lower-third overlay.
- Two mid full-bleed visual stages with big-type captions.
- Trust: hairline list + supporting plate.
- How: three steps each with a still.

## Anti-patterns

- No `#CCFF00` Kinetic cinema hero
- No `01 — Capture`, `TARGET: *.mov`, BUFFER/LATENCY sticker HUD
- Dashboard must not be the only hero visual
