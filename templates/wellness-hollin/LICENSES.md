The page loads nothing from a CDN; the Content-Security-Policy on every page is `default-src 'self'` with `script-src 'self'`.

The WebGL field (`js/field.js`) is original code: one raw WebGL2 fragment shader, no library. Cross-document page transitions use the View Transitions API in CSS, no library.
