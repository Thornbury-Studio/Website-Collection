Training mode

How each of these gets made.

  1. Pick the world before the layout

    Every site above starts from a physical or graphic world that belongs to its subject — a wood fire, a loading bay, a vector beam. The grid comes after.

  2. Bake once, animate cheap

    Noise, geometry and layout are precomputed at init. Per frame there is a lerp and maybe one trig pair. That is why a 2.5 MB Three.js scene still holds 60fps.

  3. Ship it running, not rendered

    No build step, no framework, no bundler. Every site is HTML, CSS and JavaScript you can open in a browser straight from the folder.
