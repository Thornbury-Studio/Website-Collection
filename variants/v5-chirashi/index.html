HOW IT’S MADE 操作説明

  1. The world comes first

    Each site starts from something real that belongs to its subject — a wood fire, a lit cabinet, this sheet of paper. The grid is derived from that, never from a component library.

  2. Bake once, animate cheap

    Noise, geometry and layout are computed once at start-up. Per frame there is a lerp and maybe one pair of trig calls — which is why a 2.5 MB Three.js scene still holds its frame rate.

  3. Ship it running

    No build step. No framework. No bundler. Static HTML, CSS and JavaScript that run from the file system and deploy anywhere that serves files.
