## The one thing I found and fixed

**`.vercelignore` had silently lost its main job.** Codex's
`.vercelignore` commit (`6d98837`, "Add .vercelignore so raw source video
never reaches a deploy") replaced the file's contents wholesale to add
`templates/*/src/`. In doing that it deleted `*.md`, `db/`, and
`.impeccable/` — the exact three entries a *prior* commit (`1483905`, Zane's
own) added specifically to fix a documented info-disclosure bug: "*.md docs
were publicly servable."

I checked production before touching anything:
```
GET /CLAUDE.md /PRODUCT.md /AGENT.md /PATTERNS.md /db/supabase-setup.sql
-> all 404
```
So this was **not** a live leak at the moment I found it — something else
(Vercel's own static-serving behavior for this project's config) is
coincidentally still catching these paths. But that's exactly the kind of
platform-behavior assumption a future config change could quietly
invalidate, and the file exists so the exclusion doesn't have to depend on
it. Restored the three lines alongside Codex's new ones (both sets kept —
nothing lost either direction), committed, verified still 404 in prod,
pushed as `5f4528a`.
